# PhonicsQuest - Claude Code Guidelines

## Project Overview
PhonicsQuest is an educational phonics learning application.

## Code Review Standards
- Prioritize code clarity and maintainability
- Flag any accessibility issues (this is an educational app — accessibility matters)
- Check that UI text and instructions are age-appropriate and clear
- Ensure game/learning logic is correct and handles edge cases
- Look for performance issues that could affect user experience

## When Responding to Issues
- Be welcoming and constructive
- If the issue is a bug report, try to identify the likely cause and suggest a fix
- If the issue is a feature request, evaluate feasibility and suggest an approach
- Ask clarifying questions when the issue is ambiguous

## When Reviewing PRs
- Check that new code follows existing patterns and conventions
- Verify that educational content (phonics rules, word lists, etc.) is accurate
- Ensure tests cover the key behaviors
- Flag any breaking changes

## General
- Keep responses concise and actionable
- Use code examples when suggesting changes
- Be encouraging — this is a learning-focused project!
